1. From the bench to the computer

What does reference mapping mean?

After sequencing and initial quality control, the FASTQ file holds short reads. Reference mapping asks where each of those reads best aligns on a chosen reference sequence. Reads may align on either strand, contain differences from the reference, or fail to align under the chosen settings.

Think of the reference as a map you are comparing the reads against, not as proof that the sample belongs to a particular organism. A high mapped fraction answers a different question from how much of the genome has been covered.

2. Understand the output

FASTQ → SAM → BAM → BAI

FASTQ

Sequences and base-call quality scores for each read.

SAM

A human-readable text file describing alignments to the reference.

BAM

A compressed binary representation of the alignments, useful for processing and storage.

BAI

An index that lets software retrieve alignments from regions of a sorted BAM efficiently.

3. One-time setup

Install minimap2 and SAMtools.

Open Ubuntu inside WSL2, then run these commands:

sudo apt update
sudo apt install minimap2 samtools -y

These packages only need to be installed once in your Ubuntu environment.

4. Prepare your workspace

Copy the two files into your folder.

mkdir -p ~/bioinformatics_training/part7
cd ~/bioinformatics_training/part7
explorer.exe .

In the Windows folder that opens, copy reference.fasta and reads.fastq.gz from the downloaded ZIP into the folder. Back in Ubuntu, check:

ls -lh reference.fasta reads.fastq.gz

5. Align reads

Run short-read reference mapping.

minimap2 -ax sr reference.fasta reads.fastq.gz > mapped.sam

The -ax sr preset is for short reads and produces SAM alignments. We are using single-end reads and a small synthetic reference for this beginner exercise.

6. Process alignments

Sort the BAM file and build an index.

samtools sort -o mapped.sorted.bam mapped.sam
samtools index mapped.sorted.bam

Sorting organizes alignments by reference coordinates, and indexing supports efficient access to genomic regions.

7. Interpret, do not just count

How many reads mapped?

samtools flagstat mapped.sorted.bam
samtools view -c -F 4 mapped.sorted.bam

The second command counts mapped alignment records. The exercise contains 280 reads constructed from reference regions and 20 synthetic background reads; these are dataset-design numbers, not guaranteed alignment outputs. Check what your tools actually report.

Mapping is not coverage

The reference has an intentionally uncovered middle region. Even when most reads map, some reference positions can have zero depth. Part 8 will examine depth and breadth of coverage using this same workflow.

Also remember that unmapped means there was no suitable alignment against this reference under these settings; it does not automatically indicate a failed sequencing read.

8. Ten-minute challenge

Your turn.

  1. Run the mapping, sorting, and indexing commands.
  2. Check the mapped count with samtools flagstat and samtools view -c -F 4.
  3. Explain the difference between FASTQ, SAM, BAM, and BAI.
  4. Why could most reads map while part of the reference remains uncovered?
  5. Why should an unmapped read not be labeled a failed sequencing read without investigation?
