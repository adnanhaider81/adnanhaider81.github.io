Step 01 · What are we building?

A consensus summarises the evidence.

Reference
The sequence against which the reads are aligned.
Variant call
A candidate difference from the reference, assessed from the aligned reads.
Masked consensus
A representative FASTA with selected changes applied and low-depth positions replaced by N.

A mismatch in one read is not enough to establish a variant. Depth, base quality, mapping and allele support all affect interpretation. A single consensus also does not fully describe mixtures or minor variants.

Step 03 · Use the updated reads

Make a fresh alignment.

Ubuntu terminal · Map, sort and index
samtools faidx reference.fasta
minimap2 -ax sr reference.fasta reads_part9.fastq.gz > mapped.sam
samtools sort -o mapped.sorted.bam mapped.sam
samtools index mapped.sorted.bam

This recreates the alignment using the new FASTQ. The reference FASTA index, sorted BAM and BAM index are inputs to the following steps.

Step 04 · Examine differences

Call candidate variants.

Ubuntu terminal · Call and index candidate variants
bcftools mpileup -Ou -f reference.fasta mapped.sorted.bam > likelihoods.bcf
bcftools call -mv --ploidy 1 -Oz -o variants.vcf.gz likelihoods.bcf
bcftools index variants.vcf.gz

mpileup calculates genotype likelihoods from the aligned reads. call -mv uses the multiallelic caller and writes variant sites. --ploidy 1 makes this an introductory haploid example; it is not a complete model of a mixed population.

The synthetic design target is position 877, G→A. Inspect the actual VCF rather than assuming a call was made.

Step 05 · Apply the example filter

Keep calls meeting the site-quality cutoff.

Ubuntu terminal · Filter and index variants
bcftools filter -i 'QUAL>=30' -Oz -o passing.vcf.gz variants.vcf.gz
bcftools index passing.vcf.gz

Base quality describes confidence in an individual read base. Variant QUAL is a site-level variant-call quality measure. They are different measurements.

The QUAL cutoff here is a teaching example. A high QUAL alone does not rule out systematic error, mapping bias or other artifacts; real interpretation needs the appropriate read-level evidence and validated criteria.

Step 06 · Keep uncertainty visible

Mark every position below 10×.

Ubuntu terminal · Measure depth and write the BED mask
samtools depth -aa mapped.sorted.bam > depth.tsv
awk -v OFS='\t' '$3<10 {print $1,$2-1,$2}' depth.tsv > lowcov.bed

-aa keeps zero-depth positions, including the designed gap. The depth table is one-based; BED uses zero-based, end-exclusive intervals. Reference position 1051 therefore becomes the BED interval 1050 1051, with the fields separated by tabs.

The AWK command writes one one-base interval for each position below the threshold. The mask includes the entire 1051–1400 gap and other low-depth positions.

10× is a teaching choice.

This cutoff illustrates masking. It is not a universal standard for confident base calls, and the reads and bases counted depend on alignment and filtering settings.

Step 07 · Make the FASTA

Apply the changes and the mask.

Ubuntu terminal · Create the masked consensus
bcftools consensus -f reference.fasta -m lowcov.bed passing.vcf.gz > consensus.fa

BCFtools applies the listed alternate alleles to the reference and replaces the masked positions with N.

Reference bases can remain by default.

At unmasked sites without an alternate call, BCFtools keeps the reference base. That does not prove the base was directly observed. The consensus command applies a VCF; it does not independently evaluate the original read evidence.

Step 08 · Inspect before sharing

Check the variant and the sequence.

Ubuntu terminal · Inspect the outputs
bcftools view -H passing.vcf.gz | head
samtools faidx consensus.fa
grep -v '^>' consensus.fa | tr -d '\n' | wc -c
grep -v '^>' consensus.fa | tr -cd 'N' | wc -c

The final two commands count the consensus length and its N characters. The FASTA header and line breaks are excluded.

Prefer the optional complete script?

With the practice files in your Part 9 folder, run:

Ubuntu terminal · Run the complete exercise
bash run_part9.sh

The script checks that the required tools and inputs exist, then performs the mapping, calling, masking and output checks. It prints the passing variant, coverage totals, consensus length and N count.

Use a dedicated exercise folder. Running it again replaces the generated alignment, variant and consensus files; the supplied reference and reads are retained.

Ten-minute challenge

Explain the sequence you produced.

  1. Why can a high mapping rate coexist with a region without coverage?
  2. What evidence supports the introduced G→A change?
  3. Why are there more than 350 N characters in the output?
  4. Does this single consensus describe every allele in a mixed population?
Check your reasoning

The mapping rate describes reads, not coverage at each position. The passing VCF records the introduced variant and its supporting evidence. Masking all positions below 10× includes the zero-depth gap and other low-depth regions, giving 801 Ns in this test. A single haploid consensus does not fully represent minor variants or mixtures.

If you get stuck

The intended variant is missing.

Confirm that you used reads_part9.fastq.gz and recreated the BAM in the Part 9 folder. The old Parts 7/8 reads do not contain the demonstration change. Inspect the candidate and passing VCFs and record your tool versions.

My output has fewer or more masked positions.

Check the input BAM, the samtools depth -aa command and the $3<10 mask condition. Changing the threshold or the alignment and quality filters can change which positions become N.

A command or input file cannot be found.

Use pwd and ls -lh to confirm the folder and filenames. Follow the installation step if a required tool is missing.

Include the command, its error and the software versions when asking for help. You can contact me or return to the series page.
